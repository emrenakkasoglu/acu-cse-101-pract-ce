## Checking your work

Use **Run Tests** in the Course Tasks menu, or run the challenge checks:

```bash
pytest exercises/week_02_variables/test_challenge.py
```

To check the workshop separately:

```bash
pytest exercises/week_02_variables/test_practice.py
```

The tests run each script and check its printed results. Output checks will fail
until you complete the corresponding exercises.
